# Fruity Net: Happy Harvest

A colorful family-friendly net-catching browser game made with Godot 4.7.

Catch smiling fruit with a tossable net, earn stars and unlock 30 stages across five worlds. 15 regular fruits, golden and rotten variants, playful music and controls for touch/mouse/keyboard.

All character art, sound effects, and melodies were created for this project. Soundtrack mixes use licensed Apple Loops as supporting components.
