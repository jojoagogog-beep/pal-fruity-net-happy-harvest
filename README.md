# Fruity Net: Happy Harvest

A cheerful, original fruit-catching arcade game created with Godot 4.

## Play
Open index.html through an HTTP web server, or visit the GitHub Pages game.

Use touch or mouse: tap a location, or drag your pointer and release to
throw a magical net. Catch multiple fruits at once to build JUICY combos;
avoid rotten fruit. Collect stars, earn Garden XP, and unlock new levels.

Desktop: Space/Enter to start or continue; P/Escape to pause.

## Features
- 30 levels in 5 pastel worlds
- 15 smiling ordinary fruits, golden rare, and rotten hazard
- Illustrated bunny mascot, bright in-game sprites and colorful locations
- Woven net with flight, expansion and circular catch detection
- Multi-catch combos, streak bonuses, Rainbow Fever
- Lives, time limits, score and clear objectives, local progress saves
- Progressive net upgrades, stars and Garden XP
- Touch, mouse and keyboard controls with original feedback sounds
- Five composed musical arrangements with mixed licensed Apple Loops
- No ads, accounts, external tracking or in-app purchases

## Technology and rights
Game built with Godot 4.7.2 (MIT licensed).
Original art, code, sounds, new soundtrack compositions and gameplay
created for this project. The mixed soundtrack incorporates Apple Loops,
which are not redistributed as independent source loops.

Progress is stored in the browser local game storage. Clearing site data
may reset it. Desktop and emulated mobile tests do not replace physical
iPhone playtesting.
