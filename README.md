# FRUITY NET! — Happy Harvest

A colorful, original browser arcade game featuring 30 levels, five themed worlds, kawaii fruit friends and a throw-net mechanic. Play in the browser with touch or mouse.

© PAL Studio. Original game code, hand-crafted game mechanics, UI and original graphical character assets. Music is an original arrangement that mixes melodies with Apple GarageBand Apple Loops; Apple Loop stems are not distributed separately.

This repository provides the compiled playable HTML5 build; source authoring assets and testing materials are maintained separately.
