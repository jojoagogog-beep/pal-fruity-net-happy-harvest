# Fruity Net! Happy Harvest — Adaptive Original Soundtrack (V4)

Five original world compositions: Buttercup Bounce, Lemonade Parade,
Sugarcloud Pop, Peachy Sunset Groove, and Rainbow Finale Rush.

Each uses a separately composed 32-bar base arrangement and a synchronized
counter-melody/percussion layer. The counter-layer fades in with combos,
orders and Rainbow Fever. Each world also has matching fruit-catch,
order-completion and win motifs in the world's musical key.

Production: locally authored original MIDI and audio arrangements rendered
with GeneralUser GS SoundFont v2.0.3, used under its commercial-recording
license. This repository and shipped game do not contain the SoundFont.
Please refer to the original GeneralUser GS v2.0.3 license for its source
sample provenance caveat and terms before using the music in other products.

No third-party music streaming, user tracking or music library dependencies.
The Web build lazily loads only the current world's music.
